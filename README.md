# Premium Scroll-Driven Hero Experience

A visually stunning, high-performance parallax hero section built with vanilla HTML, CSS, and JavaScript. This project features cinematic multi-layer parallax effects, smooth scroll integration, and real-time scroll data visualization.

![Project Preview](https://cdn.prod.website-files.com/671752cd4027f01b1b8f1c7f/6717795bb5aceca85011ad83_osmo-parallax-layer-1.webp)

## ✨ Features

- **Cinematic Multi-Layer Parallax**: 4 distinct layers create a deep 3D atmosphere using GSAP and ScrollTrigger.
- **Smooth Scroll Integration**: Powered by **Lenis** for a silky-smooth browsing experience across all devices.
- **Initial Load Animation**: A premium preloader sequence including a progress bar and staggered hero reveal.
- **Live Scroll Percentage**: A dynamic indicator that tracks and visualizes scroll progress in real-time.
- **Data-Driven Insights**: Interactive percentage cards that reveal themselves with sophisticated GSAP animations.
- **Premium Typography**: Uses high-end fonts like *PP Neue Corp Wide* and *PP Neue Montreal* for a professional look.
- **Fully Responsive**: Meticulously crafted to look great on desktops, tablets, and mobile devices.

## 🚀 Technologies Used

- **Core**: HTML5, Vanilla CSS3, Modern JavaScript (ES6+)
- **Animations**: [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
- **Scroll Logic**: [ScrollTrigger](https://greensock.com/scrolltrigger/)
- **Smooth Scrolling**: [Lenis](https://github.com/darkroomengineering/lenis)

## 🛠️ Setup & Usage

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Priyakumari0307/Scroll-Driven-Hero-Section-Animation.git
   ```

2. **Run Locally**
   You can use any local server to run this project. For example, using VS Code's "Live Server" extension or `npx serve`:
   ```bash
   npx serve .
   ```

3. **Enjoy the Experience**
   Scroll down to witness the parallax layers shift and the interactive data reveal!

## 📂 File Structure

- `index.html` - The structure of the landing page, including parallax layers and preloader.
- `style.css` - Custom styling, layout systems, and responsive media queries.
- `script.js` - Animation logic, Lenis initialization, and scroll-driven interactions.
